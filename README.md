# British Airways Reviews Tableau Dashboard

A Tableau dashboard project for analyzing British Airways customer reviews.

## Project Files

- `ba_reviews.csv` — British Airways customer review dataset.
- `Countries.csv` — country reference data for geographic analysis.
- `British Airways Reviews Tableau Dashboard.twbx` — packaged Tableau workbook.

## Analysis

The dashboard explores customer feedback through ratings, review trends, service-related metrics, and geographic patterns.

## Tools

- Tableau
- CSV
- Data Visualization
- Exploratory Data Analysis

## How to Use

1. Download the `.twbx` workbook.
2. Open it in Tableau Desktop.
3. Use the dashboard filters and visualizations to explore the review data.
